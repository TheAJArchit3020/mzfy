# mzfy

**Companion personal-finance app in the Moneezify ecosystem.**

## Problem
Users need lightweight, habit-friendly tools to maintain awareness of spending and debt pressure.

## Solution
MZFY provides approachable tracking and decision support aligned with debt-free outcomes.

## Architecture
**Current stack signals:** Node.js, React, TypeScript

- Product UI layer
- Finance tracking modules
- Backend-connected recommendation flows

## Scale
Suited for broad consumer adoption with progressive feature depth.

## Monetization
Free core utility with upsell into premium planning tools.

## Roadmap
- Habit streak gamification
- Shared household budgeting
- Localized finance templates

## Quick start
```bash
npm install
npm start
```

## Useful scripts
- `npm run start` — react-native start
- `npm run test` — jest
- `npm run lint` — eslint .
- `npm run android` — react-native run-android
- `npm run ios` — react-native run-ios
